    trilhas

    Seis trilhas, dezoito techs

    Cada cor do tabuleiro é uma trilha. Aprenda as três techs de uma trilha para completá-la: o rendimento dela dobra. Complete três trilhas para vencer.

    regras

    Como jogar

    Você começa com 500 XP no Hello World e anda no sentido da seta. Não há tempo limite: jogue no seu ritmo, o progresso fica salvo neste navegador.

    Casas de tech

    Pague o custo em XP para aprender. Toda vez que cair numa tech que já aprendeu, ganha 25% do custo; com a trilha completa, 50%.

    Canais

    Discord, Twitch, GitHub e DEV custam 200 XP. Rendem 25 XP com um canal, 50 com dois, 100 com três e 200 com os quatro.

    Café e Wi-Fi

    Custam 150 XP. Rendem 4 vezes o valor dos dados, ou 10 vezes se você tiver os dois.

    Comunidade e Issue

    Tire um card. Comunidade costuma ajudar; Issue é sorte ou revés.

    Code Review

    Cair em Deploy na sexta, tirar o card errado ou três duplas seguidas manda você para o Code Review. Saia tirando uma dupla ou pagando 50 XP. Na terceira tentativa sem dupla, paga e sai.

    Fim de jogo

    Passar pelo Hello World rende 100 XP. Se o XP ficar negativo, o jogo acaba. Complete três trilhas para vencer.
